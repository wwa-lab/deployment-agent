## Framework Context

Atlas Engineering Delivery Hub is the larger narrative that organizes work through Seven Mountains SDLC:

```text
M1 Planning -> M2 Estimation -> M3 Discovery -> M4 Build -> M5 Testing -> M6 Deployment -> M7 Maintenance
```

This repository should now be presented as the M6 Deployment Tool inside that larger narrative, not as the entire framework.

Atlas Phoenix Lens / Legacy Spec Factory may be mentioned as an M3 Discovery upstream capability when useful, while this repository remains focused on controlled release operations.
