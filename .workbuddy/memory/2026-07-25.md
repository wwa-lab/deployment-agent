## Resource Center SDLC 颜色降饱和（leo 反馈 "SDLC 那几个都是黑色的"）
- leo 复提审美问题：截图里左栏 1-7 数字 + 主内容 (1)(2) Planning 那些圆标 "都是黑色的，不好看，和其它导航网站有点不一样"
- 之前 7-25 决策③ "阶段圆标色彩递进" 是有意保留的 hue ramp（蓝→青，222→168，9°/step），但实现用了 `hsla(..., 72%, 52%, 0.14)` 背景 + `hsl(..., 68%, 40%)` 文字——饱和度/明度过高，在浅底侧栏里读起来像深蓝发黑，确实踩了"loud"雷
- 修正方案（不动 hue ramp 结构，只降饱和提明度）：
  - 背景 `hsla(..., 72%, 52%, 0.14)` → `hsl(..., 50%, 93%)`（半透明中蓝 → 实色极淡彩）
  - 文字 `hsl(..., 68%, 40%)` → `hsl(..., 42%, 42%)`（深艳 → 中性）
- 改动只在 `frontend/src/views/ResourceCenterView.vue` 的 `stageTone()` 一处；同时驱动 `.nav-num`（侧栏）+ `.stage-num`（主内容圆标），两端身份一致
- AGENTS.md 允许"小修小改 / 视觉调优"不走完整 SDD；design doc 没规定具体色值，Decision 8 只说"presentation values derived not stored"
- lesson：分级调色板要在浅底 + 小字号（侧栏 12px）场景下做可用性测试，深色 40% lightness 在 12px 字号下视觉感知接近黑色，下次定色要先按目标字号模拟
